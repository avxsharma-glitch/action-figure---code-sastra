# Transformers Hub - Collectible Action Figure Storefront

Transformers Hub is a premium, responsive landing page for collectors of iconic Autobots and Decepticons. It uses the existing Next.js App Router architecture, Framer Motion transitions, Lenis smooth scrolling, and real character assets.

## Experience

- Hero presentation for Optimus Prime
- Featured figure carousel for Optimus Prime, Bumblebee, and Megatron
- Collection detail cards for character design, finishes, poseability, and display editions
- Collector community section for meetups, custom showcases, fan collections, and conventions
- Character archive gallery using the available figure assets
- Community newsletter call to action

## Visual direction

- Warm ivory and cream page surfaces
- Charcoal navigation and content panels
- Restrained yellow accent
- Editorial typography and generous whitespace
- Full character presentation with `object-contain`
- Subtle shadows and spring-based motion instead of excessive glow

## Technical stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Framer Motion
- Lenis smooth scrolling
- Lucide React
